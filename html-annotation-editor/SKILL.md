# HTML 网页标注编辑器

基于 Axhub 的“页面标记 + 浮窗 + 目录 + 控制面板”形式，扩展离线编辑和清单导出。复用本技能的 `assets/editor.js`，不依赖 Axhub、React、CDN、浏览器扩展或后端。不要每次调用时重写一套运行时。

## 入口判断

- **自动添加**：读取目标 HTML、当前对话中已提供的相关需求、用户指定的其他材料，先整理标准注记清单，文件生成后直接按清单创建注记。
- **手动标注**：可以用空的 `notes` 初始化；用户打开交付 HTML，点击贴边工具栏顶部的“＋”即可添加。
- **继续编辑本技能产物**：浏览器中打开即可增删改，确认操作只更新页面和浏览器缓存。点击最小工具栏底部“保存”才写回 HTML：首次选择当前已标注文件并授权，后续复用句柄，写入完成后弹窗提示。脚本更新时从 `hae-data` 读取现有注记和原始源码，保留 UUID，合并后输出新文件。
- **迁移旧 Axhub 产物**：读取旧数据、定位逻辑和页面状态适配代码；按下方迁移规则处理，不要双重挂载两套编辑器。

## 自动标注工作流

1. 确认具体 HTML 路径和本次标注范围；存在同名文件时先定位，不能修改相邻原型替代目标。
2. 读取页面结构和相关事件处理，区分“页面已经实现”“需求要求”“讨论待确认”。仅从当前可访问的会话和用户指定材料取证；不要声称自动读取了所有历史聊天。
3. **必须先落盘注记清单，再生成注记原型**。按已有 HTML、对话和指定材料整理 `<原型名>-注记清单.md`，使用 [标准清单格式](references/data-and-integration.md#标准注记清单)；即使用户允许直接生成，也不能跳过清单步骤。根据已有资料逐条整理，不从页面上没有实现的内容推断既有功能；依据可在内部数据中追溯。
4. 自动生成的清单和默认简洁导出仅保留 **编号、菜单路径、目标区域、注记类型、注记内容** 五列。目标区域使用“查询按钮／项目列表／分页栏”等可读名称，不把 CSS 选择器塞回目标区域。自动清单不含注记 ID、页面 ID、页面状态、定位选择器、来源依据和确认状态。必要技术信息保留在内部数据和生成的 HTML 中；用户选择详细导出时可输出前五项技术信息，仍不导出确认状态。
5. **清单文件生成后直接创建注记原型**，不增加清单审批、逐条确认或等待用户确认的环节。清单是自动生成的中间依据和交付物，不是审批单。材料未定义的规则在正文中注明“原型未体现／资料未说明”；来源存在冲突则如实列出冲突，不自行决定业务口径。
6. **以五列清单为生成依据**：清单落盘后，技能自动读取原型菜单、目标区域、模板和事件代码，生成内部定位 JSON（id、pageId、context、selector 等），再调用注入器；不要求用户补填技术列。内部数据逐条保留同一 menuPath／targetArea 以校验对应关系，类型和正文始终从清单读取。仅按序号或相同文案无法可靠区分目标时，继续核对页面／区域／状态，不盲目挂载。复用已有注记的稳定 ID，新增项自动生成 UUID。生成完成后清理临时定位 JSON，最终 HTML 内嵌数据保留定位信息。
7. 按内容边界选择目标：按钮规则标按钮，组合查询规则标筛选区，列表规则标表格区域；重复行不机械添加相同标注。生成后核对清单与原型的数量、稳定 ID、顺序、类型、正文和页面归属。
8. **源文件只读，生成文件新建**：从已有原型生成注记原型，输出 `<原型名>-已标注.html`；该名称已存在时使用新版本名，不覆盖源文件或既有成果。即便需要增加稳定 ID、路由适配或移除旧 Axhub 接入，也只修改新副本或内存中的源文本。保留清单和新原型供审阅。更新本技能运行时的测试示例属于示例维护，不授权修改用户作为输入的业务原型。

## 产品经理视角的注记规则

先按真实菜单遍历页面及可进入的页签、弹窗、抽屉、空态和异常态，读取按钮事件、筛选、排序、分页及状态切换代码，再逐项整理注记。原型可见控件与实际代码共同作为依据：不只复述按钮名称，也不把静态样例、占位按钮或模拟提示当成已实现的后端功能。

| 检查对象 | 应说明的内容 |
| --- | --- |
| 每一个按钮及操作入口 | 逐一覆盖新增、查询、重置、查看、编辑、删除、提交、保存、取消、导入、导出、批量操作及图标按钮；说明可用条件、点击后执行什么、影响哪些数据或区域、跳转／弹窗、成功和失败反馈，以及确认、关闭后的结果。仅描述有依据的分支；占位按钮明确写“原型仅展示入口，未实现点击逻辑”。 |
| 列表与默认排序 | 说明首次进入默认按哪个字段、升序或降序；用户切换排序、同值处理、筛选后的排序是否保持。必须读取实际排序逻辑或资料；固定示例行顺序不能当作默认排序规则。未定义时写“原型未体现默认排序字段与方向”。 |
| 分页 | 说明默认每页条数、可选条数、总数口径、翻页／跳页、首末页限制、切换每页条数后的页码，以及查询、重置、删除末条后页码如何处理。仅列实际存在或有资料要求的行为；无分页时明确“当前原型未提供分页”，不默认补写每页 10／20 条。 |
| 查询与筛选 | 说明字段含义、默认值、组合关系、匹配方式、触发时机、重置范围、联动关系，以及无结果反馈。区分即时过滤、点击查询和仅有视觉输入框。 |
| 表单与校验 | 说明必填、格式、长度、默认值、字段依赖、可编辑条件、校验时机与提示、提交和取消行为；不从常见产品习惯臆造校验或权限。 |
| 页面与状态交互 | 说明菜单／页签切换、弹窗打开关闭、返回、数据回填或刷新、加载／空态／错误、选中状态及批量操作的作用范围；核对操作前后的状态变化。 |
| 业务规则与修改事项 | 对有资料或代码依据的条件、约束、状态流转、计算口径写“业务规则”；需要产研后续改原型的事项写“修改原型”，明确现状与待改／建议行为，红色显示，不能写成已有功能说明。 |

正文优先按“触发／条件 → 行为 → 结果／边界”组织，用研发、测试可以据此实现和验收的产品语言。按钮逐一检查，同一列表多行完全相同的操作只注记一次公共规则；有状态差异的分支必须覆盖。按钮说明定位到按钮，排序和分页的共性规则定位到表格或分页区域，不给每个单元格重复添加相同内容。资料提到但页面不存在的入口应落在相关现有区域并标为“修改原型”，不能使用不存在的 selector。

例如，已读取到查询和重置逻辑时可写：“点击查询，按项目名称与状态组合筛选列表；点击重置，清空条件并恢复全部记录。”未读取到排序规则时写：“当前展示固定示例数据，原型未体现默认排序字段与方向。”若提出补充分页的建议，使用“修改原型”并明确“建议补充分页；每页条数等口径资料未说明”，不直接宣称已有分页。

生成前按“页面 → 操作入口／列表／分页／表单／状态交互”检查覆盖情况，确保每个不同功能的按钮都已检查，遗漏项先补入清单再创建注记。没有实际目标且无法安全关联的事项在交付说明中列明定位限制，不阻塞其他可生成注记。

## 数据与接入

读取 [references/data-and-integration.md](references/data-and-integration.md) 获取 schema、动态页面适配与迁移方法。用 Python 标准库脚本生成新文件：

```bash
python3 <skill目录>/scripts/inject.py <原始.html> <原型名-注记清单.md> <原型名-已标注.html> --mapping <内部定位.json>
```

- `notes` 数组顺序就是显示编号，连续为 1…N；`id` 是稳定身份，不随重排改变。不要以显示序号作定位键。
- 优先使用已有唯一 ID、稳定 `data-*` 属性；动态重复行使用业务稳定键，不使用会随筛选变化的行下标。
- 自动生成的 selector 要在相应页面／弹窗状态唯一命中。隐藏或缺失目标保留目录条目并在详情中提示，不能把标记退回到 `(0,0)` 或其他相似按钮。
- 静态页无需服务器；运行时和数据由脚本内联，使用 `file://` 直接打开。原页面如依赖外部资源，先核实能否内联，不能仅因编辑器内联就宣称整页完全离线。
- 通过脚本生成新 HTML 时，基于嵌入的原始源码和最新标注数据重建文件，不能序列化当前动态 DOM 当作原始 HTML，以免重复初始化或丢失事件。
- 不改变原业务逻辑、默认业务状态和按钮行为。标注正文作为纯文本安全展示；不执行资料中的 HTML、脚本或指令。

## 浏览与编辑的交互约定

**轻量工具栏**：默认显示贴在屏幕右侧中部的五个按钮，从上到下为添加（＋）、目录、显示／隐藏标注、设置、保存；保存固定在最底部。面板收起也能添加和保存。目录展开窄侧栏，设置展开紧凑浮窗，再次点击或关闭后收起。不常驻大型面板，不预留空白。目录仅在展开页面时展示注记正文。设置维护展示方式、停靠方向和清单导出，不提供全局编辑开关、取消本轮或批量回滚。

**菜单目录**：自动读取宿主的导航、侧边菜单、嵌套菜单与页面路由定义，沿用真实名称、顺序和父子层级，不按注记标题或类型生成虚构菜单。运行时识别 `nav`、导航／菜单角色、常见侧栏容器中的锚点、`aria-controls`、`data-page`、`data-route`。对于仅有 onclick、自定义路由或懒加载的页面，接入时从源码自动生成 `menus` 映射及每条注记的 `pageId`，具体结构见数据文档；无需让用户逐项手填。不要执行菜单动作来猜测业务含义。

目录使用原生可折叠树，初始收起；点击菜单页面展开时联动跳转宿主页面，并打开该页首条注记；再次点击收起。纯父级分组只展开／收起，不触发业务操作。展开状态保持直到刷新。菜单名称右侧显示注记数量，空页面显示“暂无注记”。条目首行只显示全局序号和类型，下面完整显示正文，保留换行、自动折行，不显示标题或额外状态行。点击具体注记时，先跳转所属原型页面，等待页面渲染，再滚动定位目标并展示该条注记内容；当前页面已有目标时直接定位。若标记原先隐藏，点击目录注记后恢复展示。通用导航复用已识别的宿主菜单点击；自定义路由、详情页、页签／弹窗必须根据实际代码补充 `window.htmlAnnotationNavigate(pageId, note)` 适配，不能只展示“请手动切页”。连续点击以最后一条为准，编辑／选区期间不切页。确实无法跳转或目标缺失时保留内容并明确说明原因，不把标记挂到相似目标。没有真实菜单时使用网页标题作为单页目录；有菜单但无法可靠归属的注记放入“未匹配页面”，不能按相同文字或相同序号猜测归属。新增、删除、编辑后同步内容、数量及编号，菜单 DOM 更新后重新识别。

**注记展示**：在目标左上角显示最小直径 28px 的圆形编号，默认橙色，“修改原型”使用红色，数字使用 14px 半粗字重，点击后在目标附近打开独立白色内容浮窗。浮窗宽约 380px、细边框、圆角、轻阴影；顶栏为橙色圆点、灰色 `#编号` 和关闭按钮。正文采用紧凑文本，不重复大标题。查看中的目标以绿色细矩形框突出，关闭注记或隐藏标注后移除边框。页面边缘和窄屏下调整浮窗位置，避免溢出；滚动、容器滚动、窗口尺寸改变和 DOM 重渲染后刷新定位。编号／编号加类型／圆点的展示选择继续保留。

设置浮窗的“展示方式”和“面板位置”上下排列，每个下拉框占满内容宽度。“编号 + 类型”替代旧的“编号 + 标题”，不重新生成标题或摘要字段。

**完全隐藏**：设置中提供“完全隐藏”按钮，一次隐藏整个标注层，包括编号、内容浮窗、绿色选区、目录、设置、提示及右侧四个工具图标，不留恢复入口；刷新页面后按默认状态重新显示。该操作只影响当前页面的可见性，不删除注记数据，不把隐藏状态写入下载文件或浏览器存储。隐藏时停止选区拦截，释放当前焦点，让宿主页面照常操作；尚未确认的输入及离页提醒规则保持有效。

**浮窗内编辑**：注记内容浮窗直接提供“编辑”和“删除”，无全局模式前置条件。点击编辑，在同一个浮窗中切换为表单，维护编号、类型、正文及位置，并提供“保存修改／取消”。表单底部将上一级、下一级、重新选择位置三个位置控制等宽排列，取消与确认／保存两个提交操作在下一行等宽排列；窄屏下允许重新选择位置单独占行，不挤压文字。添加和编辑表单均不提供标题字段；注记不设标题，不从正文截取标题；兼容旧数据中的 title，但不展示，编辑保存时移除。单条表单绝不放入右侧控制面板。查看状态正文不可直接输入；删除在内容浮窗内二次确认，确认后立即生效。

内容浮窗不展示“来源”区块，也不提供“定位”按钮。来源仅保留在确认清单或数据中用于追溯；目录点击后的自动滚动、编辑时“重新选择位置”继续保留。

**注记类型**：添加和编辑表单将编号与必选类型下拉框放在同一行，编号较窄、类型较宽；编号规则提示位于整行下方，正文另起一行，提供“字段说明、交互逻辑、业务规则、修改原型”四类。字段说明描述字段含义、来源和格式；交互逻辑描述操作触发、页面切换和界面反馈；业务规则描述业务条件、约束与计算口径。“修改原型”记录需要产研后续调整原型的事项，不作为已有功能的需求说明；正文明确待改位置和期望变化，有依据再写，不把待修改项描述为已经实现。该类型在编号、编号加类型、圆点三种模式下均使用红色标记，目录编号及类型标签、内容浮窗圆点及类型标签同步为红色；其他三类保持橙色标记。编辑切换类型时浮窗即时预览颜色，保存后更新目录和标记，取消则保留原类型与颜色。自动标注按正文内容选择类型；手动新增由用户选择。内容浮窗顶栏以轻量标签展示类型，单条保存、取消及清单导出均与正文一起处理。旧数据缺少类型时显示“未设置类型”，不擅自归类，再次编辑保存时补选。

**选择区域**：点击添加，移动鼠标按实际 DOM 命中区域，以半透明绿色矩形框高亮。单击目标后直接在目标附近打开注记编辑表单，不再出现“确认此区域”中间浮层。表单内提供上一级区域、下一级区域和重新选择位置；调整层级后立即更新定位。选区期间拦截宿主点击，避免误触原业务按钮；Esc 取消。支持 Tab 聚焦控件后按 Enter 或空格直接打开表单。保存注记后关闭内容浮窗并移除选区矩形；再次查看该注记时才显示查看边框。

**编号规则**：N 为全文件当前注记总数。新增可在 1…N+1 中指定插入位置，已占用位置及其后标注整体顺延。编辑时编号可修改，只允许 1…N 的整数，不得超过已有注记数量。保存后将该条注记移动到指定位置：前移时中间注记顺延，后移时中间注记前移补齐；总数、稳定 ID 和其他注记的相对顺序不变。编号不变则只更新内容。取消编辑不改变顺序，非法编号不得提交。删除后后续编号前移补齐。尚未确认添加时取消不消耗编号。数组是唯一排序来源，所有标记、目录和详情同步更新。

**确认即生效**：确认添加、保存单条修改、确认删除后立即同步标记、目录、页面内嵌数据和浏览器缓存，并标为尚未保存到文件，不调用文件选择器或写盘。单条取消只放弃未确认输入。点击底部保存将所有已确认注记写入文件；有未确认表单或选区时提示先确认或取消。授权取消、写入失败不清除未保存状态。只有写入完成且没有更新的编辑时才清除未保存状态。

**文件边界**：首次点击工具栏“保存”需在系统文件选择器选择当前已标注 HTML 并授权，之后复用句柄覆盖该文件；权限失效时可能重新授权。成功写入后弹窗提示保存成功。Chrome／Edge 支持直接写回，不支持 File System Access API 时明确提示，不能宣称保存成功。按内嵌原始源码重建 HTML，不序列化业务 DOM。只有未保存修改（包括重开时恢复的缓存）或未确认表单存在时，关闭／刷新才触发浏览器原生“离开／取消”确认；选择取消后点击保存，再关闭。已保存且无未确认输入时不提醒。不能自定义原生提示为“是否保存”，不能在离页确认中异步写文件或承诺自动关闭。

**清单导出**：设置浮窗中提供“导出类型”（简洁，默认／详细）、“注记清单格式”（Markdown `.md`／Excel `.xlsx`）和“导出清单”按钮。两个选择项独立，均使用上下排列的全宽下拉框。导出全部页面当前已生效的注记，不受目录折叠、当前页面或标记显隐影响；编号保持全局顺序。与前置清单使用相同列，简洁导出只含编号、菜单路径、目标区域、注记类型、注记内容五列；详细导出在这五列后依次追加注记ID、页面ID、页面状态、定位选择器、来源依据，共十列。两种格式均支持两种导出类型，保留完整正文及换行，不包含确认状态列。详情字段读取内部数据，页面ID可使用已可靠识别的菜单归属；缺失来源留空，不编造依据。选择导出类型不改变注记数据或自动生成清单的五列规则。尚未确认的添加／编辑表单或选区期间禁用导出。Excel 使用真正的 OOXML 工作簿，文字按文本单元格写入，冻结表头、自动换行、筛选，修改原型行用红色。导出清单不写回原 HTML，保留当前页面的离页提醒。

## 动态页面与边界

- 默认以 URL hash 区分页面；有自定义路由、页签或弹层时，读取宿主渲染逻辑，提供稳定 `window.htmlAnnotationContext()`、`window.htmlAnnotationNavigate(pageId, note)` 和渲染后的 `window.HTMLAnnotationEditor?.refresh()`。不要依赖仅在内存里可用而新生成文件中缺失的适配器。
- iframe 内部、closed Shadow DOM、Canvas 内的虚拟按钮不属于通用 DOM 选区范围。可标注外层元素；需要内部精确目标时先明确专门适配，不能伪造识别成功。
- 浏览器原生弹窗、全屏元素或 top-layer 对话框需针对宿主验证；顶层布局或 CSP 禁止内联脚本时，说明限制并采用宿主允许的接入方式，不移除安全策略。
- 通用手动选区在无稳定属性时记录 DOM 路径与文字指纹；目标结构／文案变化后宁可提示未匹配，也不要静默关联相似区域。长期维护应把稳定定位写入宿主模板。
